Glossary

DFT
Density-functional theory.
DF
Density fitting: approximating four-center electron-repulsion integrals with an auxiliary basis.
J/K
Coulomb and exchange matrix construction.
RSS
Resident set size; the reported exact peak is Linux child ru_maxrss, not the sum of process-tree pages.
NBF
Number of orbital basis functions; obtained from the running engine.
MOs
Retained molecular orbitals after the common overlap-eigenvalue cutoff.
GiB
2³⁰ bytes. RSS KiB are divided by 2²⁰; NVML MiB by 2¹⁰.
Eh
Hartree, the atomic unit of energy; 1 µEh = 10⁻⁶ Eh.
GPU
Graphics processing unit; this timing panel used one H200.
H200
NVIDIA Hopper GPU used for the measured DF comparison; not interchangeable with H100 performance data.
