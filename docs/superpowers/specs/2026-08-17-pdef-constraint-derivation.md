# Native PDef Constraint Derivation

Specification for the missing `PDefConstraints` derivation required by Task 5 /
`refine_wsm` in `plans/2026-07-31-native-camcasp-parity.md`.

Derived from site point-group symmetry arguments and validated against the reviewed
model definition. No PFIT source was read while writing this.

## Why this matters

The WSM least-squares fit of a 15x15 L3 tensor per site is **under-determined** by a
finite fit-point set. Without an active-variable mask the solver fills ill-determined
directions with arbitrary values. Observed on a real STO-3G run with no constraints
supplied: the hydrogen dipole block came out with an `alpha_yz` element of `+/-5.34`
against diagonals of `~1.17`/`~0.50`, giving eigenvalues `[-4.51, -0.011, +6.19]` — a
wildly non-positive-definite dipole block. The same element moved to `+/-1.75` when the
fit-point count changed from 96 to 72, confirming it is an unconstrained direction rather
than a converged physical quantity.

The reviewed model has `alpha_yz = 0` **exactly** on both hydrogens. That zero is imposed
by symmetry, not fitted. Deriving and applying this mask is therefore a prerequisite for
any polarizability parity claim, not an optimization.

## The rule

For each site, in that site's **local axis frame**, a component pair `(t, u)` with
`t <= u` in the L3 ordering is an **active fit variable** if and only if the real spherical
harmonics `t` and `u` transform as the **same irreducible representation** of the site's
local point group. All other pairs are frozen at zero and excluded from the design matrix.

Only the upper triangle is a variable; the tensor is symmetrized as `alpha[u][t] = alpha[t][u]`.

### Classifying a real spherical harmonic

For component `l m x` (where `x` is `c`, `s`, or absent for `m = 0`), the needed characters
are generated by two operations:

- `C2(z)`: azimuthal angle `phi -> phi + pi`, so both `cos(m phi)` and `sin(m phi)` pick up
  `(-1)^m`. Character = `(-1)^m`.
- `sigma(xz)`: `y -> -y`, so `sin(m phi) -> -sin(m phi)` and `cos(m phi)` is unchanged.
  Character = `-1` for `s`-type components, `+1` for `0`- and `c`-type.

Two components share an irrep exactly when their character tuples over the site group's
generators are equal.

### Worked site symmetries for H2O

Geometry: C2 axis along `z`, molecule in the `xz` plane.

- **O** sits on both mirror planes: site group `C2v`, generators `{C2(z), sigma(xz)}`.
  Character tuple `((-1)^m, s-parity)`. Four classes:
  `A1 = {10, 20, 22c, 30, 32c}`, `B1 = {11c, 21c, 31c, 33c}`,
  `B2 = {11s, 21s, 31s, 33s}`, `A2 = {22s, 32s}`.
  Active pairs = `15 + 10 + 10 + 3` = **38**.
- **H1 / H2** lie in the `xz` plane only: site group `Cs`, single generator `sigma(xz)`.
  Character is just the `s`-parity. Two classes:
  `A' = {10, 11c, 20, 21c, 22c, 30, 31c, 32c, 33c}` (9 components, 45 pairs),
  `A'' = {11s, 21s, 22s, 31s, 32s, 33s}` (6 components, 21 pairs).
  Active pairs = **66**.

### Symmetry-copy constraint

`H2` is not fitted independently. Its tensor is a symmetry copy of `H1`, consistent with
the reviewed model definition (`H2 H2 COPY H1 H1`) and with the exact relation
`alpha_H2 = S_x alpha_H1 S_x`, `S_x = diag(-1, 1, 1)`, verified to hold in the reviewed
output at every frequency. Implement this as an equality constraint that removes H2's
variables from the design matrix rather than as a post-hoc overwrite, so residual
diagnostics stay meaningful.

## Validation status

Validated two independent ways.

### 1. Against the reviewed model *definition*

The rule was applied to the reviewed H2O model definition and compared pair-by-pair:

| site | predicted active pairs | reviewed active pairs | set difference |
| ---- | ---------------------- | --------------------- | -------------- |
| `O`  | 38 | 38 | none, both directions |
| `H1` | 66 | 66 | none, both directions |

Exact agreement on membership, not merely on count. The `H2 COPY H1` relation is also
present in the reviewed definition.

### 2. Against the reviewed model *output*

Stronger check, independent of the definition file: every entry of the reviewed 15x15
tensors that the rule marks forbidden should be identically zero. Scanning all eleven
frequency blocks:

| site | forbidden entries checked | max abs value on a forbidden entry | max abs value on an allowed entry |
| ---- | ------------------------- | ---------------------------------- | --------------------------------- |
| `O`  | 1804 | `0.000e+00` | `1.895e+02` |
| `H1` | 1188 | `0.000e+00` | `4.204e+01` |

Exactly zero, not merely small. The reviewed model freezes precisely the degrees of freedom
this rule predicts, so applying the mask removes exactly the right directions from the fit.

### Why this fixes the observed pathology

For a `Cs` hydrogen the dipole block spans `(10, 11c, 11s)`. The rule allows `10-10`,
`10-11c`, `11c-11c` (all `A'`) and `11s-11s` (`A''`), and forbids `10-11s` and `11c-11s`.
In local Cartesian `(z, x, y)` those two forbidden pairs are exactly `alpha_zy` and
`alpha_xy`. So the mask forces `alpha_yz = alpha_xy = 0` by construction — which is the
`+/-5.34` element that the unconstrained fit was inventing, and which the reviewed model
reports as exactly zero.

The mask constrains *which* entries may be nonzero. It does not by itself guarantee the
correct *values* on the allowed entries; those still depend on the response stage.

## Implementation notes

- Site groups must be **derived** from the molecule and the local axis definitions, not
  hard-coded for H2O. The generator set for a site is the subgroup of the molecular point
  group that leaves that site fixed. Fail closed if a site's local frame is inconsistent
  with the detected symmetry rather than guessing.
- Determine characters with an exact integer/sign computation, not a floating-point
  tolerance test, so the mask is reproducible.
- Freezing must happen by **omitting columns from the design matrix**. Do not fit and then
  zero: that changes the residual and defeats the conditioning benefit, which is the
  entire point.
- The plan's Global Constraints require preserving full L3 tensors and exposing a
  diagnostic when a reviewed model reports non-positive-definite higher-rank blocks. The
  mask legitimately removes the *dipole*-block pathology above, but must not be used to
  silently repair genuinely non-positive-definite higher-rank blocks.
- Expected effect on conditioning: active variables drop from 360 (3 sites x 120 upper-
  triangle pairs) to 104 (38 for O, 66 for H1, 0 independent for H2).
